# Phase 19: Phone brain
Status: Stage: Done | Round: 3/3 | Updated: 2026-11-16 21:20

## For Tim
This phase lets Wally think on your phone when the laptop is off. Clear commands still go to the fast code, but anything unclear is answered by a small AI model running on the S25 itself, shown word by word. It only runs when the phone is above 20% battery and not in power saving; otherwise the home server answers as today. The home server still checks every answer before anything is saved.
It starts with a test only you can do: you try the model in Google's "AI Edge Gallery" app and copy the model file to the phone. If it is too slow or uses too much battery, we stop and choose together. A second early check makes sure the model can give Wally's fixed answer form on your phone.
Two builders work in parallel: one on the phone and shared app code, one on the home server and the guides. Ideas from Codex that I took: the server stays the only one that saves; each phone answer starts fresh (no hidden memory between chats); careful handling when the app is closed mid-answer; a fair speed measure (first word you see, not first hidden character); and a precise record of model, size and speed.
You are approving: the phone model replacing the old "no local model" rule, the model library and file in the tech list, and a new "Phone brain" card in Settings.
