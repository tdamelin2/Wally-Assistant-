# W8 checklist: Files, Dream journal, AI jobs, Goals (PLAN Tasks 8.1-8.7)

Run it on BOTH apps: the phone app and the installed laptop app (Wally 1.6.0). Use the sync button (the arrows icon) whenever a step says Sync. Tick a line only when it really passed; write "skipped" next to a line you did not run. Use made-up test text only, and delete it at the end.

Install order (important):
- [ ] First deploy the server: `powershell -ExecutionPolicy Bypass -File ops\deploy-server.ps1`. Only after it finished, install the new apps. (An old server rejects the new kinds of entries and the apps would mark them "Rejected".)
- [ ] Install the laptop app `Wally-1.6.0.msi` and the phone app (versionName 1.6.0, versionCode 2) over the old ones. Both open and still show the name Wally.
- [ ] Old entries are still listed: check-ins, spending, journal, tasks and meals you saved before the upgrade appear in the Log tab on both apps, and a Sync shows no "Rejected" line.

Reaching the new screens (More menu and sidebar):
- [ ] Laptop (wide window): the left sidebar lists Today, Log, Charts, Health, Chat, Files, Dream, Goals. Shrink the window height: the list scrolls and Settings and the sync button stay at the bottom.
- [ ] Phone: the bottom bar shows Today, Log, Health, Chat, More. Tap More: a sheet lists Charts, Files, Dream, Goals. Open Files: More shows as selected.
- [ ] On Chat, Files, Dream and Goals (phone) there is no floating + button covering the screen. On Today and Log it is still there with its five entry types (Check-in, Spending, Journal, Task, Meal).

Resize (laptop):
- [ ] Open Files, start a new doc and type a title and some text. Drag the window narrower than the phone-width threshold and back. The typed text is still there.
- [ ] Same for the Dream form (New dream, type text, resize narrow and wide).

Files (SPEC 2 #5):
- [ ] Phone: Files > New folder `Test folder`. New doc: title `Hello doc`, text `# Heading` then a line `- one` then `**bold** and *italic*`. Save. Sync both apps: the doc and the folder appear on the laptop.
- [ ] Laptop: rename the doc to `Hello doc 2` (the three-dot menu, also right-click on the row), move it into `Test folder` (three-dot menu), edit the text, Sync. The phone shows the new name, the folder and the new text (long-press the row on the phone also opens the menu).
- [ ] Phone: delete the doc, Sync. It disappears on the laptop.
- [ ] Delete the folder while it still holds a doc: the doc stays and now shows under `No folder`.
- [ ] Search on the phone for a word that is only inside a doc's text (not its title). The doc is found. Turn on airplane mode and search again: still works.
- [ ] Preview: open a doc, press Preview. Headings are large, bullets have a dot, bold and italic show, and a link `[Example](https://example.com)` is clickable and opens the browser. Text like `**not closed` stays as plain text.
- [ ] Hebrew: make a doc titled `שלום` with a line `זה טקסט בעברית`. The text is right-to-left in the editor and in the preview. A line in English in the same doc is left-to-right.
- [ ] Longest text: paste a very long text (about 200 000 characters). Save works; adding more than 200 000 shows `Too long` and Save is disabled. Preview of the long doc scrolls without freezing.
- [ ] Press Back in the editor after typing: it asks `Discard your changes?`.

Dream journal (SPEC 2 #6):
- [ ] Dream tab > New dream: date today, mood 4, tick Lucid, tags `Water, Flying , water`, text `I was flying over a lake`. Save. The list shows the dream with its date, mood, lucid and tags `water, flying, water` (tags are lowercased and tidy).
- [ ] Sync. The dream appears on the other app.
- [ ] Edit the dream: change the text, Save. The edit appears after Sync on the other app. Delete a second test dream: it disappears after Sync.

Job line (SPEC 2 #6, laptop closed):
- [ ] Close the laptop app completely. On the phone, open the dream and press `Interpret`, then Sync. The line under the button reads `Queued — runs when Wally is open on the laptop`.
- [ ] Open the laptop app (the XPS Ollama must be on). Within 1 minute of opening it the job runs. Write the time it took: ______ .
- [ ] On the phone press Sync: the dream now shows an interpretation, and the status line is gone. Opening the dream shows the text and the model name.
- [ ] Turn the XPS Ollama off, press Interpret on the laptop: the line stays `Queued...` / `Working…` and the dream is not marked failed; turn Ollama on again and it finishes within about 2 minutes.
- [ ] With at least 3 dreams in the last 30 days press `Find patterns (last 30 days)`. After the laptop runs it, the Dream tab shows `Patterns, <date>` with a text on both apps.
- [ ] On the `Patterns, <date>` card open the three-dot menu and press Delete: a dialog asks `Delete this pattern summary?`. Cancel keeps it; Delete removes it on both apps after sync. Press `Find patterns` again the same day: a new `Patterns, <date>` appears.

Goals (SPEC 2 #7 and #8):
- [ ] Goals > New goal: `Run 10 km`, why `health`, deadline 60 days from today. It opens its detail page. Progress reads `0 of 0 tasks done`.
- [ ] Press `Plan steps`. After the laptop runs it, 3 to 10 suggested steps appear with ticked boxes. Untick one and press `Add selected as tasks`: the message says `Added N tasks`, the tasks appear in the Log > Tasks list and in the goal detail. Press the button again: `Nothing new to add.`
- [ ] Tick a task of the goal (in the goal detail or in Log > Tasks): progress changes to `1 of N`. Tick it on the Today tab: same. After a Sync the other app shows the same progress.
- [ ] Open a task in the Log, set `Goal` to your goal in the form and Save: it now counts in the goal's progress. Toggle that task's checkbox in Log: its goal link stays.
- [ ] Plan my ideal week: on Goals type `Mornings free for the gym, work 9 to 5, Friday afternoon off` and press the button. After the laptop runs it, Files > Plans has a doc `Ideal week <date>` with a plan, marked AI.
- [ ] Delete the goal: it leaves the list; its tasks stay in the Log.

Dream privacy (spot check):
- [ ] Open Chat and ask `What did I dream about last night?` The answer says it has no such data (dreams are never given to chat). Today's morning briefing also does not mention dreams.

Clean up:
- [ ] Delete the test docs, folder, dreams, goals and tasks you made, and Sync.
